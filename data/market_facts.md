**Consequence for the pitch:** the plan says "for micro-importers near 50 t there is nothing" — that is no longer true; SME tools start at €79/month. Our differentiation instead:
1. reads invoices (PDF) instead of manual product entry,
2. built for the importer *below/near* 50 t: threshold monitor + forecast + "this order will push you over",
3. Austria-specific: AnEH application checklist, German UI, Kärnten example,
4. every number links to the legal source; deterministic code with tests.

Suggested price that undercuts the cheapest SME tool: free check, monitoring €19–49/month (as in the plan), white-label for Spediteure / Steuerberater.
